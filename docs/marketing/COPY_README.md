# Atom — GitHub copy kit

This copy is grounded in the local acceptance and first-use evidence. It does
not claim hosted deployment, universal reliability or qualified model judgment.

## Short description

Open-source AI employees that learn your business rules, work with spreadsheets
and documents, and resume durable tasks after a restart.

## Headline

Teach an AI employee your business. Give it work. Come back to a result.

## Introduction

Atom turns company data and taught methods into repeatable local work.
Upload a spreadsheet, confirm unfamiliar fields, calculate against source
records and create a cited document. When information is missing, the employee
asks and saves its state so you can leave and continue later.

## First-use invitation

Try the sample locally: Python 3.11–3.13, Node.js 20.9+, Git and Make.
Run `PYTHON=python3.11 make setup`, `make dev`, then `make sample` in a second
terminal. The expected result is **232990.00** and a downloadable DOCX.
The sample needs no cloud key, connected account or live send.

## Proof, with scope

- **111/123 frozen functional claims (90.2%) accepted** within documented local
  and controlled-provider configurations. This is coverage, not accuracy.
- **About 5 min 15 s measured first use with warm package caches** on one host.
  A 15-minute cold install remains a target.
- Teaching, corrections, unfamiliar-data mapping and durable restart/resume have
  recorded UI/runtime evidence with named sources.
- One specifically authorized Outlook send and Microsoft read-only ingestion
  were separately accepted. Broader live sending, autonomous live sending,
  connector breadth and independent recipient delivery remain unqualified.
