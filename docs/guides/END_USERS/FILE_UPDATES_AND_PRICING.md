# File Updates & Pricing Accuracy — End-User Guide

How your agents stay current with your files (price lists, quotes, stock),
and how to get accurate numbers when it matters.

**Last Updated:** September 2026

---

## When agents see your edits

| You edit a file in… | The agent sees the change… |
|---------------------|----------------------------|
| WorkDrive / Drive / OneDrive / Dropbox / Box | Within seconds if real-time updates are enabled by your administrator, otherwise within the hourly sync |
| Any connected app | Always available immediately if you ask the agent to **open the file** (it reads the live version) |

If you're not sure real-time is enabled, ask your administrator — or just
use the "open the file" phrasing below, which always reads the current
version.

---

## Getting accurate prices and figures

**To check the current price of something, say:**

> "Open the price list and give me the current price of the WG350DSAV"

The word **"open"** makes the agent read the live file rather than rely on
its memory of it.

**When the agent quotes a figure, it shows the date**, like:

> $14,145 — per the Consolidated Price List (as ingested 2026-09-04)

That date is when the copy the agent read was taken. If the date is old and
the number matters, say *"re-open the file and confirm"* — the agent will
re-read it and confirm or correct.

---

## Good habits

- **Cite the row, not the vibe.** Ask *"show me the row you got that from"* —
  the agent can point to the exact sheet and row (e.g. LINMAC, row 17).
- **Prices in sent emails don't update themselves.** If a price list changes
  after a quote went out, the agent will use the new price next time — but it
  won't rewrite history. Ask it to *"compare the current price list against
  the quote we sent Mark"* if you need a diff.
- **Edits are safe to make.** Updating a file never breaks the agent — it
  re-reads the new version automatically. You can also say *"check the
  price list again"* to force a fresh look.

---

## If something looks wrong

| Symptom | What to say / do |
|---------|------------------|
| Agent quotes an old price | *"Open the price list and confirm the current price of X"* |
| Agent says it can't find a file | Ask it to *"search WorkDrive for <file name>"* — and check the file is in a folder that's been connected to Atom |
| Agent's number doesn't match your file | Tell it the correct value (like the LINMAC row) — and ask it to *"re-open the file"*, which makes it read the live copy |
| Nothing updates at all | Ask your administrator whether real-time updates are enabled and the hourly sync is running |
