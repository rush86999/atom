# Supported workflows — demonstrated core CSV loop

> **Support status: CSV-only package.**
> This package does not certify the expanded core. See the successor package
> tagged `expanded-core-2026-10-28` for email, documents, PowerPoint, the
> Excel-like canvas and the cross-material employee job.

Verified on DeepSeek `deepseek-flash` with the packaged configuration:

1. Upload a representative CSV/workbook through the product UI.
2. Create a canvas, attach an agent and teach a task-owned policy.
3. Run an unfamiliar assessment with the taught decision vocabulary.
4. Run deterministic selection and explicit sum/count calculations over the
   complete eligible dataset, with row/cell citations, source hashes and named
   missing-input gaps.
5. Correct the same teaching point in place.
6. Run a different unfamiliar assessment.
7. Restart the backend; teaching, source identity, results and history persist.
8. Run a fresh post-restart assessment.
9. Complete the loop with zero unauthorized side-effect writes.

# Not certified by this package

Email, PowerPoint, document generation, broad integration sync, scheduling,
marketplace, autonomous evolution, streaming and other common-data surfaces
are not certified by the CSV assessment loop. They require their own evidence.
Whole-app certification is not claimed.
