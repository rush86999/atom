# Supported workflows

## Workbook / Excel-like canvas
Upload an XLSX; open the workbook canvas and verify sheets, headers, text
identifiers, blanks and numeric values. Filter the displayed rows without
changing the workbook. Edit a precedent cell; supported dependent formulas
recalculate and the formula source remains distinct from the displayed value.
Unrelated cells/sheets survive. Save, restart/reopen and download an XLSX whose
values and formulas agree.

## Email
Import an EML with an attachment. The canvas preserves sender, To/Cc, subject,
body, RFC Message-ID/References and the attachment association. An editable
reply draft is prepared; it survives reload/restart. Import/drafting never
sends. Imported attachments are source evidence and are marked non-sendable.

## Documents
Read a DOCX including real tables. Generate a real editable DOCX with grounded
content/calculations, source references, requested headings and real tables.
Apply a correction to the saved document; reopen and download it with matching
content.

## PowerPoint
Read a PPTX including slide text, tables and speaker notes where present.
Generate a real PPTX with grounded facts/calculations, sources, correct slide
order, tables and notes. Apply a correction; reopen and download it with
matching content.

## User-created table canvases
Install a versioned capability manifest, bind a CSV/XLSX dataset, map the
subject/measure/status fields, declare editable fields and task-owned decision
options/policy. The server exposes only the intersection of declared
operations, installed adapter support, owner/workspace permission and current
resource support. Selection, deterministic sum/count, certified assessment,
authorized edit/readback and XLSX export are available when declared.

## One bounded employee job
Import an email request, workbook and supporting document/deck; teach a
task policy; inspect evidence; calculate in the workbook canvas; assess table
rows; prepare a reply draft; generate a document and deck; apply a correction;
run an unfamiliar variation; restart and verify teaching, workbook state and
deliverables.
